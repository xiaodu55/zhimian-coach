# 演示视频脚本（知面陪练 · 知乎黑客松）

> 配套自动录屏脚本：`scripts/demo/record-demo.mjs`
>
> ```bash
> node scripts/demo/record-demo.mjs --dry      # 只打印分镜，不启动浏览器
> node scripts/demo/record-demo.mjs            # 真实录制，产物在 out/demo-<时间戳>.webm(+mp4)
> node scripts/demo/record-demo.mjs --headed   # 想自己盯一眼时用有头模式
> ```
>
> 本文件是**分镜与口播稿**（人怎么说、评委要看什么）；录屏脚本负责**画面怎么动**（点哪里、等多久、失败了怎么兜底）。两者分开的原因：口播要人写，画面要机器跑，但必须严格对齐同一套时间轴。

---

## 0. 一句话定位（视频开场别说产品名，先说痛点）

> 「你刷了几百道题，一开口还是说不清。知面陪练不给你更多题，它给你一个**会一直追着你问**的面试官。」

这句话是整条视频的主线：**不是题库，是陪练**。后面每一段画面都要为它添一块证据。

## 3. 录制前准备清单

### 3.1 服务与账号

- [ ] **本地服务已起**：`node scripts/dev/restart.mjs 8787`，浏览器能打开 `http://127.0.0.1:8787/`。
- [ ] **模型与知乎密钥可用**：`/api/health` 返回 `{ok:true, zhihuConfigured:true, llmConfigured:true}`。密钥未配置时服务仍能起，但会**降级**——此时复盘台只有规则层诊断、没有四维评分和 AI 追问，**录出来的东西说服力会打折**。录制前务必确认一次。
- [ ] **知乎登录**：演示全程不需要用户登录知乎（我们用服务端密钥拉语料）。但若你打算在视频里点开"看知乎原答 ↗"做现场核对，需要在**录屏用的那个浏览器 profile 里**登录一次知乎，避免跳到登录页穿帮。
- [ ] **网络**：知乎开放平台是限流的。录制前先完整跑一遍 `--dry` 之外的真机流程（`node scripts/test/smoke.mjs`），确认题库能加载出带观点卡的题。

### 3.2 示例回答怎么准备

- [ ] **不需要提前准备**：陪练页上的「试一试：填入一段示例回答」会按当前题的领域自动挑一段贴合的示范回答（AI Agent / RAG / 后端 / 论文答辩各有各的版本）。录制时直接点它即可。
- [ ] 如果你希望视频里出现**你自己的经历**（更有说服力），就提前把一段 150–300 字、带具体数字的回答粘贴好；但要注意脚本每轮都会自动重填示例，覆盖手输内容。**要留手输内容就别用自动脚本，用 `--headed` 手动走一遍。**
- [ ] 至少 15 字，否则提交按钮是灰的（这是刻意的门禁）。

### 3.3 时长与超时

- [ ] **第 5 步（生成复盘）要 10–60 秒**：模型链路实测 17–24 秒，上限 25 秒/次；追問深度 2 轮就是**两次**模型调用，最坏接近 60 秒。录屏脚本对此给了 **180 秒**总预算并用轮询 URL 判断，不靠固定 sleep。
- [ ] **建议提前录好，不要现场录**：黑客松现场的网络和模型服务都可能抽风。正确做法是**提前跑一遍录屏脚本**，产出 `out/demo-<时间戳>.webm`（自动转 mp4），提交时直接上传文件。
- [ ] 想要一条"零等待"的备用素材：在题库首屏点「🧯 离线演示（预置复盘）」，它会载入一份预置报告，可以立刻录复盘台画面。**这条只作备份**，正式视频请用真实链路。

### 3.4 隐私（这条最容易翻车，务必逐条确认）

- [ ] **不要上传真实简历**：简历解析是本机处理，但一旦录屏里出现真实公司名、真实项目名、手机号、身份证号，就是公开事故。演示用**项目文档 / 论文节选**时先脱敏。
- [ ] **不要带真实录音**：录制用 `--headed` 或脚本录制时都**不碰麦克风**，脚本走的是"填入示例回答"路径。不要在正式演示里点「开始录音」。
- [ ] **不要带真实答辩材料**：答辩预测那一步用页面上的「先看一份示例材料的追问 →」即可，示例材料是内置的 Agent 权限模型方案。
- [ ] **浏览器窗口干净**：录制前关掉个人标签页、通知、密码管理器弹窗；用无痕或独立 profile 更稳。
- [ ] **终端不要入镜**：录屏只录浏览器页面，但如果你用「屏幕录制」而非脚本录制，终端里的 `.env`、密钥、真实日志都要藏好。**优先用脚本录制**，它只录浏览器 viewport。

### 3.5 产物检查

- [ ] 脚本跑完会打印 `webm：` 与 `mp4：` 两行路径。**大多数平台只收 mp4**，没有 ffmpeg 时脚本会打印一条现成的转码命令，手动跑一遍即可。
- [ ] 打开 mp4 通看一遍：有没有黑屏段、有没有停在 loading 上、有没有录到不该录的浏览器插件弹窗。
- [ ] 成片时长在 3–5 分钟（完整版）或 90 秒（精简版）区间。

## 4. 字幕 / 剪辑建议（3 条）

1. **闭环要剪出来，不要只讲出来**
   字幕固定打上五个动作词：`选题库 → 拆逻辑 → 模拟练 → 抗压追问 → 看复盘 → 弹药库`。这六个词就是产品的认知动线，评委扫一眼字幕就知道你做了什么，而不是"打开了一个网页"。每个镜头左上角打一个当前动线词。

2. **知乎溯源要"看得见"，不能只是说**
   凡是用到知乎观点的地方，剪辑时给那个 chip / 链接加一个 0.5 秒的放大或高亮框（鼠标指针保持在链接上不要点走）。评委会把它和口播里的"知乎原文溯源"对上——**说了但没看见，等于没说**。

3. **本地隐私用画面证明，不要用嘴说**
   不要只念"数据在本机"。在弹药库那段把「🔒 本地存储」「导出 JSON」「清理音频」「重置本机」这几个按钮**框出来**，配一句"服务端零落盘"。隐私是这类产品的第一决策点，**画面证据比文案承诺强十倍**。

## 5. 常见事故预案

| 症状 | 原因 | 处置 |
|---|---|---|
| 复盘台只有规则层诊断、没有四维分数 | 模型降级（密钥没配或模型超时） | 现场不解释技术原因，直接说"这轮模型服务在忙，这是纯规则层的确定性诊断，同样能指到原话"；然后切到预置复盘素材兜底 |
| 卡在"模型生成中"超过 60 秒 | 模型服务挂 | 录屏脚本会自动跳过这一步继续录后面的画面，不会整段崩；正式视频用提前录好的版本 |
| 弹药库没有闪卡 | 没做过复盘或没点「存入我的弹药库」 | 先在复盘台点一次「📌 存入我的弹药库（本地）」，再切弹药库 |
| 答辩预测点「开始预演」没反应 | 材料没加载 | 先点「先看一份示例材料的追问 →」载入内置示例材料 |
| 视频只有 webm 上传失败 | 平台不收 webm | 用脚本打印的 ffmpeg 命令转 mp4；或 `ffmpeg -i in.webm -c:v libx264 -pix_fmt yuv420p -crf 23 -movflags +faststart out.mp4` |
