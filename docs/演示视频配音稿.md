## 剪辑与字幕建议（只留三组关键词就够）

1. **闭环动线**：`读懂 → 说清 → 被追问 → 查清楚`（首屏 2 秒淡入）
2. **溯源要看得见**：所有出现「知乎原文溯源 / 看原答 ↗」的地方，用细框高亮 0.5 秒
3. **隐私用画面证明**：切到弹药库顶部那行「本地已用 35.9 KB · 导出 JSON」，框一下 —— 不念也比念更有说服力

**不要**加背景音乐以外的花哨转场；评委要的是"这东西真的能用"，不是特效。

## 录屏脚本自检（录完对着看这 6 条）

1. 首屏标题与「知乎原文溯源」字样是否清楚（1440×900 录制，字太小评委看不清 → 剪辑时放大这一段）
2. **34–50 秒的追问必须出现**（模型慢时这段可能延后，别剪掉）
3. 复盘台要看到「三方对照」三个栏目（你的回答 / 知乎主流 / 知乎分歧）
4. 弹药库要看到闪卡上的**掌握度按钮**（生疏/熟练/随时可讲）
5. 答辩预测要看到**片段切分**和「知乎上的相关讨论」
6. 全片**不能出现**真实简历名、真实手机号、真实公司面试记录

## 已知会踩的坑

| 现象 | 原因 | 处理 |
|---|---|---|
| 34–50 秒空等 | 首次结构化输出慢（10–30s），或模型降级 | 录制前先跑一次复盘"预热"模型；追问段落建议**录两遍**取快的 |
| 弹药库闪卡是空的 | 录屏 profile 是新的，没有历史数据 | 录屏脚本已内置"先种一张闪卡"；若仍为空，手动在复盘台点一次「存入我的弹药库」再录 |
| **公网版录屏跳过 3 处**（种子闪卡没种上 → 空库 → 翻牌超时） | 公网首屏要 10s+，脚本用固定 1.2s 等待就判"按钮不存在" | 已修：改为等元素出现（`waitForSelector`，20s）。**公网版重录后 0 处跳过**，以 `demo-2026-11-20T15-16-13.mp4` 为准 |
| 画面里出现「示例：Agent 权限模型方案.md」 | 答辩预测的示例材料 | 这是**故意**的示例，不是隐私，保留无妨 |
| 视频上传被拒 | mp4 需 H.264 | 脚本已用 libx264 转码；仍失败就 `ffmpeg -i in.mp4 -c:v libx264 -crf 23 -c:a aac out.mp4` |
